# Hangzhou BYGL Global Trading Company - Corporate Website

Site web corporate complet, bilingue (Français / Anglais), responsive et interactif conçu pour **Hangzhou BYGL Global Trading Company**, entreprise de commerce international enregistrée à Hangzhou, Province du Zhejiang, Chine.

---

## 📌 Fonctionnalités Clés

- **Bilinguisme Instantané (FR / EN)** : Module dynamique en pure JavaScript conservant la langue sélectionnée.
- **Identité Corporate Haut de Gamme** : Palette de couleurs sur variables CSS (Bleu Marine, Ardoise, Or).
- **Parcours Client Interactif** : Diagramme complet avec 3 flux distincts (Bleu: Acheter un produit, Vert: Devenir partenaire, Orange: Demander un projet) et gestion des branches de refus.
- **Formulaires Fonctionnels & Sécurisés** : 
  - Demande de devis de sourcing (avec pré-remplissage des catégories)
  - Proposition de partenariat
  - Soumission de projets (commercial, industriel, eau potable)
- **Bouton WhatsApp Flottant** & Liens Réseaux Sociaux (+86 185 1629 8726).
- **SEO & Performance** : Code sémantique HTML5, CSS optimisé et sans dépendances lourdes.

## 🚀 Déploiement sur GitHub & Vercel

### 1. Versionnement sur GitHub
```bash
git init
git add .
git commit -m "Initial commit - Website BYGL Corporate"
git branch -M main
git remote add origin https://github.com/votre-compte/hangzhou-bygl-website.git
git push -u origin main
```

### 2. Déploiement sur Vercel
1. Connectez-vous sur [Vercel](https://vercel.com).
2. Cliquez sur **"Add New Project"** et importez le dépôt GitHub `hangzhou-bygl-website`.
3. Laissez les paramètres de Build par défaut (Static Site).
4. Cliquez sur **"Deploy"**.
